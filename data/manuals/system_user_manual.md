## SM-OVR-001 | 시스템 개요 및 주요 기능

본 시스템은 FAB 내 모든 공정 설비의 센서 데이터를 실시간으로 수집·분석하여 이상을 사전에 감지하고 알람을 발생시키는 FDC(Fault Detection & Classification) 플랫폼입니다.

**핵심 기능 7가지**
1. **실시간 모니터링**: 30종 이상 설비의 SVID(Status Variable ID) 데이터를 1Hz로 수집·표시
2. **이상 감지 알람**: 통계적/룰 기반 모델로 임계치 초과 또는 패턴 이상 감지
3. **알람 원인 추정**: 알람 발생 시 유사 과거 사례 및 가능한 원인 후보 자동 제시
4. **Trend Chart**: 설비별 센서 추이 조회 (최대 90일 이내 원본 데이터)
5. **Recipe/Lot/Chamber 검색**: 다양한 기준으로 알람·이벤트 검색
6. **알람 임계치 관리**: 임계치 확인 및 변경 신청
7. **VOC 등록/조회**: 시스템 사용 중 발생한 문의·이상 등록

**주요 사용자 그룹과 기본 권한**
| 역할 | 코드 | 주요 권한 |
|---|---|---|
| 설비 엔지니어 | EQ_ENG | 알람·trend 조회, VOC 등록, 임계치 변경 신청 |
| 공정 엔지니어 | PROC_ENG | EQ_ENG 권한 + 임계치 변경 승인, recipe 조회 |
| 운영 담당자 | OP | 대시보드 조회, 알람 ack, VOC 등록 |
| 현장 대응 담당자 | FIELD | 대시보드 조회, VOC 등록 |

세부 권한은 [운영 정책 POL-PERM-001]을 참조하세요.

## SM-LOGIN-001 | 로그인 및 권한 확인

**접속 URL**: `https://fdc.example-fab.internal` (사내망 전용)

**로그인 절차**
1. 사번 + 사내 SSO 비밀번호 입력
2. 2-Factor 인증 (OTP) 입력 — 보안 정책상 필수
3. 로그인 직후 우상단 프로필 아이콘에서 본인 역할(role)을 확인

**로그인 실패 시**
- "권한 없음" 메시지 → 시스템 접근 권한이 미부여된 상태. [운영 정책 POL-ACC-001]에 따른 접근 권한 신청이 필요합니다.
- 비밀번호 오류 5회 누적 시 사내 SSO 정책에 따라 계정이 잠깁니다. 사내 IT 헬프데스크에 문의하세요.

## SM-MON-001 | 실시간 모니터링 대시보드

대시보드 첫 화면은 **3개 영역**으로 구성됩니다.

1. **알람 위젯 (상단)**: 최근 24시간 내 발생한 알람을 Severity 별로 카운트 표시. Critical 알람은 적색 깜빡임으로 표시됩니다.
2. **설비 상태 그리드 (중단)**: 등록된 30대 설비의 현재 상태 — `PRODUCTION` / `IDLE` / `ALARM` / `MAINTENANCE` 4가지 색상으로 구분.
3. **트래픽 패널 (하단)**: 시간대별 알람 발생 추이 (heatmap)

설비 카드 클릭 → 해당 설비의 상세 페이지로 이동 (Trend Chart, 알람 이력, 처리 현황).

> **참고**: 설비 그리드의 색상과 실제 설비 상태가 다르게 표시되는 경우 통신 단절일 가능성이 높습니다. [FAQ-003]을 확인하세요.

## SM-ALM-001 | 알람 조회 및 필터 사용법

좌측 메뉴 **알람 → 알람 이력** 으로 이동합니다.

**검색 가능한 필터**
- 기간 (기본: 최근 24시간, 최대 2년 이내)
- 설비 ID (예: `THIN-CVD-02`)
- 알람 코드 (예: `TEMP-H-001`)
- 알람 카테고리 (TEMP / PRES / FLOW / RF / VAC / GAS / HV / DOSE / CHEM / COMM / REC / MECH)
- Severity (Critical / High / Medium / Warning / Info)
- 처리 상태 (OPEN / ACKNOWLEDGED / CLEARED)
- Chamber, Recipe ID, Lot ID

검색 결과는 발생 시각 내림차순으로 표시되며, 각 행을 클릭하면 알람 상세 화면이 열립니다. 알람 상세에서는 다음 정보를 확인할 수 있습니다.
- 알람 코드 의미 (자동으로 alarm_code_guide 해당 섹션 링크)
- 발생 시점의 주요 센서 값 (snapshot)
- 같은 설비의 직전 24시간 동일 코드 발생 이력
- 권장 SOP 링크 (있을 경우)

알람 이력의 기본 보존 기간은 2년입니다 ([POL-DATA-001] 참조).

## SM-ALM-002 | 알람 임계치 확인 및 변경 신청

**임계치 확인**
- 알람 코드 상세 화면 우측 패널의 "임계치 정보" 섹션에서 현재 적용 중인 임계치 값과 마지막 변경일을 확인할 수 있습니다.
- 임계치는 알람 코드별/설비별로 다르게 설정될 수 있습니다.

**임계치 변경 신청 절차**
1. 알람 상세 화면 우측 상단 `[임계치 변경 신청]` 버튼 클릭
2. 변경 사유, 변경 전/후 값, 검토자(공정 엔지니어) 지정
3. 제출 → 승인 워크플로우 진입

**중요**: 임계치 변경 신청은 EQ_ENG 이상 누구나 등록할 수 있으나, **승인은 PROC_ENG 이상만** 가능합니다. 자세한 권한 매트릭스는 [POL-PERM-002]를, 신청 절차의 정식 양식은 [POL-CHG-001]을 참조하세요.

## SM-TRD-001 | Trend Chart 조회

좌측 메뉴 **Trend → Trend Chart** 로 이동합니다.

**조회 절차**
1. 설비 ID 입력 또는 검색 (예: `THIN-CVD-02`)
2. Chamber 선택 (해당 설비가 멀티 챔버일 경우)
3. 표시할 센서(SVID) 선택 — 최대 6개 동시 표시
4. 기간 선택 (기본: 직전 1시간, 최대 90일)
5. `[조회]` 클릭

**차트 인터랙션**
- 마우스 드래그: 구간 선택 → 자동 확대
- 더블 클릭: 원래 배율로 복귀
- 우상단 `[CSV 다운로드]`: 표시된 데이터 CSV 내보내기 (역할별 제한 있음)
- `[알람 마커 표시]`: 차트 위에 같은 기간 알람 발생 시점을 마커로 오버레이

**Trend 원본 데이터 보존 기간은 90일입니다** ([POL-DATA-001] 참조). 90일 초과 데이터는 1분 평균값으로 다운샘플된 형태로만 조회됩니다.

## SM-TRD-002 | Trend Chart 조회 오류 해결

가장 흔한 Trend Chart 조회 오류와 대응법입니다.

**증상 1 — 차트 영역이 비어 있음**
- 원인 후보: ① 선택 기간 동안 해당 SVID의 데이터 수집이 없음 ② 설비 통신 단절 시기 ③ SVID 매핑이 누락됨
- 확인 방법:
  - 같은 설비의 다른 SVID는 표시되는가? → No이면 통신 단절 의심 ([COMM-W-001], [COMM-W-002] 참조)
  - 다른 설비도 같은 SVID가 비어 있는가? → Yes이면 데이터 수집 시스템(DAQ) 측 이슈
- 모두 정상인데도 누락된 경우 VOC `데이터 누락 문의` 카테고리로 등록해 주세요.

**증상 2 — 일부 구간에 데이터가 끊김**
- 원인 후보: 센서 통신 일시 단절 (수 초 이내)
- 대응: 끊김이 지속적/주기적이면 [FAQ-003] 또는 [SOP-COMM-001]을 참조하세요.

**증상 3 — 조회 버튼을 눌러도 응답 없음**
- 원인 후보: ① 선택 기간이 너무 길어 (예: 90일 전체) 서버 timeout ② 브라우저 캐시 이슈
- 대응: 기간을 7일 이내로 줄여 재조회. 그래도 응답 없으면 시스템 접속 오류 가능성 → VOC 등록.

**증상 4 — CSV 다운로드 버튼이 비활성화**
- 원인: 역할별 다운로드 권한 제한 ([POL-PERM-001] 참조). EQ_ENG 이상 권한 필요.

## SM-SRC-001 | Recipe / Lot / Chamber 기준 검색

좌측 메뉴 **검색 → 통합 검색** 에서 다음 기준으로 데이터를 검색할 수 있습니다.

| 검색 키 | 형식 | 예시 |
|---|---|---|
| Recipe ID | `R-{eq_type}-{2자리}` | `R-CVD-15` |
| Lot ID | `LOT-{YYYYMMDD}-{3자리}` | `LOT-20260512-017` |
| Chamber | 설비 ID 선택 후 chamber 선택 | `THIN-CVD-02 / CH-A` |

각 기준으로 검색하면 해당 키와 관련된 **알람 이력 / Trend 데이터 / VOC 처리 이력**이 통합 표시됩니다.

특정 Lot의 처리 이력 추적 시 가장 자주 사용되는 화면입니다. 동일 Lot이 거친 설비 순서대로 알람·이상 이벤트가 시계열로 나열됩니다.

## SM-VOC-001 | VOC 등록 방법

좌측 메뉴 **VOC → 신규 등록** 클릭.

**입력 필드**
| 필드 | 필수 | 설명 |
|---|---|---|
| 제목 | 필수 | 50자 이내 요약 |
| 본문 | 필수 | 상황·증상·재현 절차 등 자세히 작성 |
| 카테고리 | 필수 | 10개 카테고리 중 선택 (드롭다운) |
| 우선순위 | 필수 | LOW/NORMAL/HIGH/URGENT |
| 설비 ID | 선택 | 관련 설비가 있을 경우 |
| 알람 코드 | 선택 | 관련 알람이 있을 경우 |
| 첨부파일 | 선택 | 스크린샷, 로그 등 (10MB 이하) |

등록 후 자동으로 담당자가 배정되며, 처리 상태는 `OPEN → IN_PROGRESS → RESOLVED → CLOSED` 흐름을 따릅니다. SLA는 [POL-SLA-001]을 참조하세요.

**작성 팁**
- 알람 코드를 명시하면 자동으로 관련 매뉴얼 섹션이 응답에 포함됩니다.
- 우선순위 `URGENT`는 라인 정지를 유발하는 경우에만 사용해 주세요. 남용 시 알람 시스템 자체의 SLA 운용에 영향을 줍니다.

## SM-VOC-002 | VOC 상태 조회

본인이 등록한 VOC는 좌측 메뉴 **VOC → 내 VOC** 에서 조회할 수 있습니다.
다른 사용자의 VOC를 조회하려면 VOC ID(예: `VOC-2026-0042`)로 직접 검색하세요.

**상태별 의미**
- `OPEN`: 등록되었으나 담당자가 아직 배정/확인 전
- `IN_PROGRESS`: 담당자가 배정되어 조치 중
- `RESOLVED`: 조치가 완료되어 등록자 확인 대기 중
- `CLOSED`: 등록자 확인 완료 또는 자동 종료(48시간 미확인)

**VOC ID로 답변 자동 추천 받기**
VOC 등록 시 본 시스템의 AI 응답 Agent가 매뉴얼·SOP·과거 VOC를 검색하여 1차 답변을 자동 생성합니다. 자동 답변은 다음 6개 섹션을 포함합니다.
1. 요약 답변
2. 근거 문서
3. 상세 설명
4. 권장 조치
5. 추가 확인 질문
6. 신뢰도 점수

신뢰도가 낮거나 근거 문서를 찾지 못한 경우 자동 답변에 명시적으로 표시되며, 담당자가 별도로 응답합니다.
